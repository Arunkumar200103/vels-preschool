Buds 'n' Blossoms – cropped image assets

Source: supplied 1536 x 1024 homepage collage.
These are rectangular crops from the flattened image, so some crops retain
nearby background, text, borders, or neighbouring decoration. They are not
transparent cut-outs and should be treated as visual reference assets.

Folders:
- section-crops/: larger section/background crops
- components/: individual visual regions cropped from the design

For a production React site, recreate headings, body text, buttons, navigation,
cards, and contact details as HTML/CSS. Use the crop images as visual artwork.
